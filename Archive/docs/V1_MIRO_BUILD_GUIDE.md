## SPACING & ALIGNMENT
- **Horizontal spacing:** Equal distance between each image (120-150px apart)
- **Vertical alignment:** All images aligned at same height
- **Labels:** 20-30px above each image
- **Captions:** 20-30px below each image
- **Summary section:** 80-100px below last image

---

## COLOR SCHEME (Match Prototype section)
- Title: #2A2A2A (dark gray)
- Labels: #34A853 (green, matches brand)
- Captions: #757575 (muted gray)
- Arrows: #CCCCCC (light gray)
- Summary background: #F5F5F5 (light) or white
- Summary text: #2A2A2A (dark)

## QUICK STEPS TO BUILD

1. **Add V1 title** at top of empty space below Prototype
2. **Arrange 7 images horizontally** in sequence (1→7 left to right)
3. **Add label text above each image** (Setup, Floors, Floor Plan, etc.)
4. **Add caption text below each image** (use descriptions above)
5. **Draw arrows connecting each image** showing the flow
6. **Add "V1 Key Features" summary section** at bottom with feature list
7. **Align everything** to match Prototype section style

## STYLING TIPS
- Match the Prototype frame's border/shadow style for consistency
