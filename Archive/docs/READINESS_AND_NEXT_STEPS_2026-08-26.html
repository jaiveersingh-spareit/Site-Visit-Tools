Site Visit App Readiness

Where the internal build stands today, what stops it going to Luxembourg, and the shortest path to a real field trial.

Prepared 26 August 2026 · Jaiveer Singh · For Lowell, Carine, Laurent, Romain

Not field-ready today. Roughly 1.5 days of work away.

The app has a working end-to-end capture flow and a built email export. It is not broken. It is unfinished in four specific places, and two of them would fail silently on the day — after the auditor has already done the work.

None of the four needs a backend decision. All four are fixable before the first week of September.

What stops it shipping

01

The email key is blanked at build time

Blocker

The deploy config sets the SendGrid key to an empty string for production. That empty value overrides whatever is set in the hosting dashboard. Export would fail every time, and the auditor would see a generic error after a full day of capture.

Fix: delete the two env lines from the deploy config and set the key in the dashboard only. ~10 minutes

02

No evidence the site was ever published

Blocker

The project folder has the deploy config and the serverless function, but no version control and no link to a live site. Nobody on this thread has a URL to hand Carine. Everything else is moot until this is confirmed.

Fix: confirm or create the deployment, then post the URL in channel. ~30 minutes

03

A big visit will exceed the export size limit

High

Photos compress to roughly 150KB each, and encoding for email adds another third. The hosted function accepts about 6MB per request — near 30 photos. A multi-floor site goes past that, and the failure lands at the end of the day when the data is already captured.

Fix: export per floor instead of per visit, and warn the auditor at the threshold. ~half day

04

Photos sit in browser storage with a hard ceiling

High

Photos are held in local browser storage, capped near 5–10MB. This one bites mid-visit rather than at the end, and can lose captured work. It is the same constraint that drove the July backend conversation.

Fix for the pilot: export after each floor, which clears the buffer. Proper fix is the backend decision, still parked. covered by 03
