# Spare-it Site Visit Form v3.0 - Phone Testing Quick Start Guide

**How to download and test on your phone in 5 minutes**

---

## 📱 For iPhone Users (Safari or Chrome)

### Step 1: Download the File
1. On your iPhone, open **Google Drive** (or your email with the link)
2. Find the file: `Spare-it_site_visit_form_UPDATED.html`
3. Tap the **three dots (⋮)** next to the file
4. Select **"Download"**
5. File will download to your **Files** app

### Step 2: Open in Safari
1. Open **Files** app
2. Navigate to **Downloads** folder
3. Tap on `Spare-it_site_visit_form_UPDATED.html`
4. Select **"Open in Safari"**
5. App will load (wait 2-3 seconds)

**OR Open in Chrome:**
1. Open **Files** app
2. Tap on `Spare-it_site_visit_form_UPDATED.html`
3. Select **"Open in Chrome"**

### Step 3: Start Testing
- Click **"Start Visit"** to begin
- Follow the test checklist from the Excel file
- ✓ All features work on phone!

---

## 🤖 For Android Users (Chrome)

### Step 1: Download the File
1. On your Android, open **Google Drive** (or your email)
2. Find the file: `Spare-it_site_visit_form_UPDATED.html`
3. Tap the **three dots (⋮)** next to the file
4. Select **"Download"**
5. File will save to **Downloads** folder

### Step 2: Open in Chrome
1. Open **Chrome** browser
2. Tap the **three-line menu (≡)** in top-right
3. Select **"Downloads"**
4. Find `Spare-it_site_visit_form_UPDATED.html`
5. Tap to open (will load in Chrome)

### Step 3: Start Testing
- Click **"Start Visit"** to begin
- Follow the test checklist from the Excel file
- ✓ All features work on Android!

## ⚡ Quick Tips

| Problem | Solution |
|---------|----------|
| **File won't open** | Make sure you downloaded the `.html` file (not a folder) |
| **App is blank** | Wait 3 seconds for it to load, then refresh page |
| **Can't find Downloads** | Swipe down from top of home screen, search "Files" (iPhone) or check Chrome → Downloads |
| **Want to test offline** | The app works without internet! Just download and open the file |
